# Geist (self-hosted)

Source: official `geist@1.9.2` npm package, `dist/fonts/geist-sans/Geist-Variable.woff2`.
License: SIL Open Font License, included in LICENSE.txt.

The font is served from this site with font-display: swap and a same-origin preload.
No Google Fonts, font CDN, runtime font package or external font requests are used.
DESIGN.md uses weights 300, 400 and 500 from this variable file.
