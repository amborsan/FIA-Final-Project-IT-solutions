# Backend → Frontend handoff

The backend developer announces contract changes here so the frontend team can
update types and screens.

## Template

```md
### Changed/Added: <METHOD> <path>
- Date:
- Related frontend ticket: FE-...
- Change:
- New/changed fields:
- Breaking: yes/no
- Frontend action:
- Status: announced | implemented
```

When a frontend ticket is implemented, the backend developer should also mark the
ticket `IMPLEMENTED` here so the frontend developer can update
`client/src/lib/types.ts` and finish the UI.
